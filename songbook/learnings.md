# 学んだこと（作る前に必ず読む）

## ユーザーの好み
- 目標は「原曲に限りなく近いオマージュ」。Sランク = 原曲そっくりの雰囲気、Aランク = ジャンルは合っていて曲としてまとまっている
- 歌詞は直接的すぎるとダサい（「ヘルメットを脱いで」「鋼の胸を叩け」は NG）。比喩や情景でにじませる
- 「D-BRAVER」のような短い英語のタイトル的な言葉は OK。「MIDNIGHT SIREN」のようなベタな英語の決め文句は NG
- 原曲が暗いのに明るく・速くしない。前に作った曲の雰囲気を引きずらない
- スマホで操作しているので、コピーしやすいように1つずつコードブロックで出す。見出しと歌詞は分けずに完成版で出す

## Suno 語彙辞典（Style に書いた言葉 → 実際に起きたこと）
| 言葉 | 結果 | 評価 |
|---|---|---|
| anime rock opening / anime | シンセ入りの王道アニソンになる | ✗ 使わない |
| synth pads and brass | シンセが入る | ✗ バンド曲では使わない |
| royal road（王道進行）など進行名 | ありがちな曲に寄る | ✗ |
| raw live band sound, indie guitar rock | バンド感は出るがポップ寄り | △ |
| early 2000s soft visual kei rock | V系に寄った（Aランク） | ◎ |
| twin guitars panned wide left and right / melodic running bass / wide fast vibrato | V系らしさが出た（上と同時に使用） | ○ |
| Exclude: J-pop, pop punk | ポップ寄りを防げた（推定） | ○ |
| fast 178 BPM, driving drums with kick on every beat, intense emotional delivery, soaring high choruses（まとめて使用） | X のようなスピードメタル寄り。Aメロからずっと全力、最高音が上がりすぎ | ✗ 速さ・激しさを言葉で足さない。BPM の数字だけにする |
| early 2000s visual kei rock（soft なし） | メタル寄りに振れやすい | △ メロディアス・メインストリームなどで方向を決める |

## 原曲とSuno版の比較でわかったこと
- Suno は放っておくと、Aメロからサビまで同じ強さで歌う。原曲に強弱があるなら、Style と歌詞の見出しの両方に「Aメロは静か・単声」「サビは声を重ねる」と書く
- 原曲のAメロのボーカルは左右の相関 1.0（真ん中に1本）、サビは 0.94（重ねた声が左右に広がる）。こういう「声の重ね方の変化」もオマージュの大事な要素

## 作詞の技法チェック（出す前に lyric_check.py で確認）
- 1番と2番、サビどうしの行ごとの音数の差は2音以内（同じメロディに乗せるため）
- サビの1行目は、短く、母音が開く音（あ・お）で始めると張りやすい
- 2回目以降のサビは最後の1〜2行だけ変えて、物語を進める
- 前の曲で使った言葉（光・夜明け・残響・硝子 など）は使い回さない
- ジャンルに合った言葉づかい: V系 = 耽美・比喩・情景、インディーズ = 日常の切り取り、特撮 = 情景で使命をにじませる

## 作り方の手順（毎回）
1. 原曲を analyze.py で解析
2. アーティストのジャンル・年代を調べる
3. コード譜を U-FRET → J-Total の順で探す（コードだけ使う）
4. Style = ジャンル＋年代 → 測った音の事実 → 組み立て → 声。Exclude = 原曲にない要素
5. 歌詞を書いて lyric_check.py で確認し、直してから出す
6. 予想点と理由を添える
7. ユーザーの点数とダメ出しを history.md と、この learnings.md に足す
8. できれば Suno 版の音も送ってもらい、analyze.py → compare.py で原曲と比べる
